# Documentación del portafolio

Hoja de vida web de Valentina García Flórez · https://valentinagarciaflorez.vercel.app

Cada archivo cubre **un solo tema**. Si algo cambia, se actualiza en su archivo y
no se copia en otro: así la documentación no se contradice.

| Archivo | Qué responde |
|---|---|
| [producto.md](producto.md) | Qué es la página, para quién, qué contiene cada sección |
| [estilos.md](estilos.md) | Colores, tipografías, componentes y reglas visuales |
| [decisiones.md](decisiones.md) | Por qué está como está y qué ya se probó y se descartó |
| [contenido-y-material.md](contenido-y-material.md) | Reglas de texto, cómo agregar fotos y videos, privacidad |
| [tecnico.md](tecnico.md) | Stack, dónde vive cada cosa, problemas resueltos, publicación |
| [pendientes.md](pendientes.md) | Lo que falta, ordenado por tipo |
| [historial.md](historial.md) | Línea de tiempo de todo lo trabajado hasta la versión publicada |

Las instrucciones operativas para sesiones de Claude están en
[`../CLAUDE.md`](../CLAUDE.md). La guía para Valentina, escrita sin jerga, está en
[`../README.md`](../README.md).

## Cómo mantenerla

- **Se tomó una decisión o se descartó una opción** → `decisiones.md`, con el porqué.
- **Se publicó un cambio** → una entrada en `historial.md` con fecha y número de solicitud.
- **Se resolvió o apareció un pendiente** → `pendientes.md`.
- **Cambió una sección, un texto de estructura o un estilo** → `producto.md` o `estilos.md`.
- **Se resolvió un problema técnico que costó encontrar** → `tecnico.md`.

Este repositorio es **público**. Nada de lo que se escriba aquí puede incluir datos
personales de Valentina, correos o cuentas de terceros, ni cifras de clientes que
no estén ya autorizadas (ver [contenido-y-material.md](contenido-y-material.md)).
